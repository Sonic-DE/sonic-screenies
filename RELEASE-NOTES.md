# Sonic Screenies Release Notes

Screenies is SonicDE's screenshot and screen recording app: capture your whole screen, a window or a region, annotate it and share it.

## 6.8.2 (2026-11-10)

- Now presents itself with SonicDE names and identity throughout the desktop.

## 6.8.0.1 (2026-10-24)

- Window captures now include the window frame, and capturing a see-through window no longer pulls in whatever was behind it.
- Screenies now recovers cleanly when a video recording fails to start or stops unexpectedly.

## 6.8.0 (2026-10-20)

- Spectacle is now Sonic Screenies, with a new Sonic-themed icon and SonicDE names throughout.
- Screenshot keyboard shortcuts, such as the Print Screen key, work again.
- The Screenies window no longer shows up in your full-screen screenshots.
- Capturing a window with see-through areas no longer includes the content behind it.
- Behind the scenes: updated to build against SonicDE 6.8.0 and a version number update.

## 6.7.5.2 (2026-09-20)

- Spectacle is now Sonic Screenies, with a new Sonic-themed icon.

## 6.7.5.1 (2026-09-19)

- Screenshot keyboard shortcuts, such as the Print Screen key, work again.

## 6.7.5 (2026-09-12)

- Behind the scenes: version number update.

## 6.7.4.2 (2026-08-23)

- Behind the scenes: simpler, more reliable detection of the image-processing library during builds.

## 6.7.4.1 (2026-08-10)

- Fixed video recording problems caused by picking the wrong colour format.

## 6.7.4 (2026-08-04)

- Picking the window under your mouse pointer works correctly again, and pressing Escape now cancels a capture as expected.
